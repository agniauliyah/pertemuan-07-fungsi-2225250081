## Ringkasan Fungsi
- `salam(nama, kelas)`: menampilkan salam.
- `luas_persegi_panjang(panjang, lebar)`: menghitung luas.
- `jumlah_n(n)`: menjumlahkan bilangan dari 1 sampai n.
- `statistik(data)`: menghitung minimum, maksimum, dan rata-rata.
- `tampilkan_scope(x)`: menunjukkan variabel lokal dan global.
- `luas_segitiga(a, t)`: menghitung luas segitiga.
- `faktorial(n)`: menghitung faktorial menggunakan perulangan.
